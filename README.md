# EdumIA - Chatbot Interactivo para Profesores

**EdumIA** es un proyecto interactivo diseñado para ayudar a profesores a resolver dudas académicas, pedagógicas o administrativas de manera rápida y eficiente mediante un chatbot especializado.

🔗 **Demo en vivo:** [https://sailok25.github.io/edumia/](sailok25.github.io/EdumIA/)

---

## 📌 Características
- ✅ **Respuestas instantáneas** a preguntas frecuentes.
- ✅ **Disponible 24/7** desde cualquier dispositivo.
- ✅ **Recursos educativos** recomendados para el aula.
- ✅ **Interfaz minimalista y moderna** con Tailwind CSS.

---

## 🛠 Tecnologías Utilizadas
- **HTML5** y **Tailwind CSS** para el diseño.
- **Font Awesome** para iconos SVG.
- **Botpress** para el chatbot interactivo.

---

## 🚀 Cómo Usar el Proyecto
1. **Abrir el chatbot**:
   - Haz clic en el botón **"Abrir Chatbot"** en la página principal.
   - Se abrirá una ventana de chat en la esquina inferior derecha.

2. **Hacer preguntas**:
   - Escribe tu duda en el chat (ej: *"¿Cómo puedo ayudar a un niño que no se integra porque es timido?"*).
   - El bot responderá con información clara y recursos útiles.
